- UI browser module runtime `plugins/browser-host.tsx` exports host types and React bridge. Shared imports MUST resolve to the same host React/SDK: initial supported packaging contract is `setup({React, sdk, ...})` with module component exports implemented using the supplied React (no bundled private React). Parent build can additionally publish shared ESM import-map assets later; do not bundle a second React. Host passes fixed `tab`, `piboSessionId`, state/updateState, scoped request and AbortSignal. Registrations are constrained to effective declared contribution IDs and own lifecycle.
- `plugins/session-tab-controller.ts`: per-session controller owns SDK CAS tabset, serialized saves, original-session closure, explicit conflict/reload keeping local edits for export. Switching session does not retarget controller. No implicit v1 migration.
- `plugins/plugin-workspace.tsx`: same manifest-driven workspace at desktop/narrow; generic subview/config scopes, missing-plugin fallback and recovery independent of loaded shell.
- `plugins/build-context-view.tsx`: recorded builds list/read from management API, distinct pure preview from session plan; no legacy context-build API calls.
