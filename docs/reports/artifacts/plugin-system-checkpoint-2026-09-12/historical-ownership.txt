## Working agreement

Everyone edits only their owned files in this one isolated topic worktree. No Git commits or branch operations by workers. The orchestrator commits integrated milestones. Never overwrite another worker's edits. Publish exact exports and proposed integration patches for shared files instead.

Use `/tmp/plugin-system-validation.lock` inside the Docker worker with `flock` for commands that compile, write dist or execute suites. Keep edits parallel. Gateway/browser readiness is coordinated with the orchestrator. No controller gateway or Pibo2 mutation by workers.

Early contract files describe real chosen APIs; do not invent a second manifest, selection, config, persistence or runtime resolution model. Read other owners' handoffs as they become available and resolve differences in your own layer.

The full plan is copied under `docs/plans/unified-plugin-system-rebuild.md`. AP11 must pass before broad AP12–14 extraction. Preparation and fixtures may be researched earlier. Retirement never aborts runs or deletes sessions. User resources and manual subagents remain independent. A written module is not an accepted package; evidence must reach the default product path.
